## 🧪 **O que o método VISA analisa**
- Semântica que gera bloqueio automático.  
- Palavras e estruturas que reduzem compatibilidade.  
- Indicadores indiretos de idade lidos pelo algoritmo.  
- Ruídos de linguagem no LinkedIn que afetam visibilidade.  
- Padrões de vagas que escondem filtros geracionais.  
- Casos reais de rejeição e reconstrução de perfis.  

---

## 📊 **Resultados esperados**
O método VISA permite:

- Aumento imediato de compatibilidade ATS (*média registrada: +35% a +77%*).  
- Redução de viés por senioridade sem ocultar trajetória.  
- Ajuste de narrativa para clusters desejados.  
- Detecção de frases que os sistemas penalizam.  
- Melhora real em entrevistas por clareza semântica.  

---

## 🧩 **Para quem este projeto serve**
- Profissionais 40+ e 50+ buscando recolocação.  
- Pesquisadores de ATS, viés algorítmico e IA aplicada a RH.  
- Empresas que desejam auditoria de processos seletivos.  
- Recrutadores que precisam compreender distorções nos filtros automáticos.  
- Criadores de conteúdo sobre carreira, tecnologia e vieses.  

---

## 🚀 **Roadmap do Projeto**
- Expandir base de testes com diferentes plataformas de ATS (Gupy, Kenoby, Indeed).  
- Adicionar casos reais anonimizados.  
- Criar uma lista pública de palavras com risco alto de ageísmo algorítmico.  
- Disponibilizar um microframework de escrita neutra para currículos.  
- (Exploratório) Protótipo de ferramenta para ajustar semântica automaticamente.
