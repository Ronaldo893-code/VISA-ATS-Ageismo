# VISA-ATS-Idadismo

Repositório criado para desenvolvimento do método VISA aplicado ao Ageísmo em ATS.
Conteúdos, testes, prompts, análises e validações serão adicionados aqui conforme o avanço do projeto.

Este repositório também serve como base de versionamento e como ponto de demonstração pública para recrutadores e parceiros.
