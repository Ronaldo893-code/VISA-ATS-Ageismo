# VISA-ATS-Idadismo  
Análises técnicas do método VISA aplicadas à linguagem de vagas, filtros ATS e sinais de viés geracional em processos seletivos.

---

## 📌 O que o método VISA analisa
O método identifica padrões que normalmente passam despercebidos pelos candidatos:

- Semântica que gera bloqueio automático pelo ATS.  
- Palavras e estruturas que aumentam ou reduzem compatibilidade.  
- Indicadores indiretos de idade lidos pelo algoritmo.  
- Ruídos de linguagem no LinkedIn que afetam visibilidade.  
- Padrões de vagas que escondem filtros geracionais.  
- Casos reais coletados e detalhados ao longo do projeto.

---

## 🎯 Resultados esperados
O método VISA permite:

- Aumento real de compatibilidade ATS (média registrada: **+35% a +77%**).  
- Redução de leitura de antiguidade sem ocultar trajetória.  
- Ajuste de narrativa para clusters desejados.  
- Detecção de frases que os sistemas penalizam.  
- Melhora na performance de entrevistas por clareza semântica.
